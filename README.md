# 🐶 Цифровой питомец на C++

![C++](https://img.shields.io/badge/C%2B%2B-17-blue?logo=cplusplus)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)
![Status](https://img.shields.io/badge/задания-11%2F11-brightgreen)

Консольная игра-тамагочи: вы заводите питомца, кормите его, играете с ним, укладываете спать и следите, чтобы он вырос здоровым.

Практическая работа №1 по дисциплине «Алгоритмизация и программирование» — **«Создаём своего первого цифрового питомца!»**.
Выполнена программа максимум: все обязательные задания, все задания для самостоятельной работы и 4 собственные характеристики питомца.

### Собственные дополнения

| Характеристика | Шкала | Как работает |
|----------------|-------|--------------|
| ⚡ Энергия | 0–100 | Тратится на игры, восстанавливается сном. Без энергии питомец не играет |
| ❤️ Здоровье | 0–100 | Падает, если питомец голоден, грязный или без сил. Лечится у ветеринара |
| 🛁 Чистота | 0–100 | Уменьшается каждый день и после игр. Восстанавливается купанием |
| 🎂 Возраст | дни | +1 день за каждое действие. Малыш → подросток → взрослый |

Также добавлено: действия «Искупать» и «Полечить», защита от ввода букв вместо числа, цель игры (победа) и разные концовки.

## 🎮 Правила игры

**Цель:** помочь питомцу дожить до **30 дней** и вырасти.

| Действие | Эффект |
|----------|--------|
| 1 — Покормить | голод −30, настроение +5 |
| 2 — Поиграть | настроение +30, голод +15, энергия −20, чистота −10 (нужно ≥ 20 энергии) |
| 3 — Уложить спать | энергия +40, голод +10 |
| 4 — Искупать | чистота +40, настроение −5 |
| 5 — Полечить | здоровье +30, настроение −10 |
| 6 — Посидеть рядом | ничего не меняется, просто проходит день |
| 0 — Выйти | завершить игру |

**Каждый день** питомец сам по себе: голод +5, настроение −5, энергия −5, чистота −5.

**Здоровье падает**, если: голод > 80 (−10), чистота < 20 (−10), энергия < 10 (−5).

**Игра проиграна**, если голод дошёл до 100, настроение до 0 или здоровье до 0.

## 🔧 Сборка и запуск

### Linux / macOS

```bash
g++ -std=c++17 src/main.cpp -o pet
```

```bash
./pet
```

### Windows (MinGW)

```bash
g++ -std=c++17 src/main.cpp -o pet.exe
```

```bash
pet.exe
```

### Visual Studio

1. Создать пустой проект C++ (консольное приложение).
2. Добавить в него файл `src/main.cpp`.
3. Запустить (`Ctrl + F5`).

> Программа сама переключает консоль Windows на UTF-8 (`chcp 65001`), чтобы русский текст отображался правильно.

Пошаговые версии из методички собираются так же, например:

```bash
g++ -std=c++17 steps/step1_birth.cpp -o step1
```
