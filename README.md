# Цифровой питомец на C++

Практическая работа №1 по алгоритмизации и программированию: «Создаём своего первого цифрового питомца!».

Это консольная игра в духе тамагочи. Заводишь щенка, кормишь, играешь с ним, укладываешь спать. Если продержать его 30 дней, он вырастет.

Я сделал все три обязательных шага, все четыре задания для самостоятельной работы и добавил питомцу ещё четыре характеристики.

## Задания

Обязательные шаги лежат в папке `steps`, по одному файлу на шаг, как в методичке:

1. `step1_birth.cpp`: питомец рождается, программа выводит его имя (`cout`, `string`).
2. `step2_stats.cpp`: появляются голод и настроение (`int`).
3. `step3_dialog.cpp`: программа спрашивает, что сделать, и обрабатывает ответ (`cin`, `if / else if`).

Самостоятельная работа сделана в `src/main.cpp`:

- голод и настроение не выходят за 0 и 100, за это отвечает функция `limit()`;
- третье действие «Уложить спать» (потом добавил ещё три);
- имя питомца вводит пользователь, через `getline`;
- задание со звёздочкой: цикл `while` крутится, пока питомец жив.

## Мои характеристики

Кроме голода и настроения у питомца есть:

- энергия (0–100). Тратится на игры, сон её восстанавливает. Если энергии меньше 20, играть он отказывается;
- здоровье (0–100). Падает, если питомец голодный, грязный или совсем без сил. Лечится у ветеринара;
- чистота (0–100). Каждый день понемногу падает, после игр сильнее. Купание её возвращает;
- возраст в днях. За каждое действие проходит день. До 10 дней питомец малыш, до 20 подросток, потом взрослый.

Ещё в игре можно поставить паузу с сохранением, а если ввести букву вместо цифры, программа не ломается и просит повторить.

## Правила

Цель: дожить до 30-го дня.

| Действие | Что меняется |
|---|---|
| 1. Покормить | голод −30, настроение +5 |
| 2. Поиграть | настроение +30, голод +15, энергия −20, чистота −10 (нужно хотя бы 20 энергии) |
| 3. Уложить спать | энергия +40, голод +10 |
| 4. Искупать | чистота +40, настроение −5 |
| 5. Полечить | здоровье +30, настроение −10 |
| 6. Посидеть рядом | ничего, просто проходит день |
| 0. Пауза | игра сохраняется, программа закрывается |

Каждый день сам по себе: голод +5, настроение −5, энергия −5, чистота −5.

Здоровье отнимается, если голод больше 80 (−10), чистота меньше 20 (−10) или энергия меньше 10 (−5).

Концовок две. Если питомец прожил 30 дней, на экране будет «ГАВ-ГАВ!» и собачка с косточкой. Если голод дошёл до 100 или настроение либо здоровье упали до 0, это поражение, и программа пишет, из-за чего.

Пауза записывает показатели в файл `pet_save.txt` рядом с программой. При следующем запуске игра спросит, продолжить ли. После победы или поражения файл удаляется.

## Как запустить

Сначала скачать проект и зайти в его папку:

```bash
git clone https://github.com/olsh2zz/mypet.git
```

```bash
cd mypet
```

Можно и без git: на странице репозитория Code, потом Download ZIP. Тогда после распаковки:

```bash
cd ~/Downloads/mypet-main
```

Все команды ниже надо запускать именно из папки проекта, где лежат `src` и `steps`. Если компилятор пишет `no such file or directory: 'src/main.cpp'`, значит, вы не в той папке.

На Linux и macOS:

```bash
g++ -std=c++17 src/main.cpp -o pet
```

```bash
./pet
```

Если на Mac нет `g++`, его ставит команда:

```bash
xcode-select --install
```

На Windows с MinGW:

```bash
g++ -std=c++17 src/main.cpp -o pet.exe
```

```bash
pet.exe
```

В Visual Studio: создать пустой консольный проект C++, добавить в него `src/main.cpp` и запустить через Ctrl + F5. На Windows программа сама переключает консоль на UTF-8 (`chcp 65001`), иначе русские буквы превращаются в кракозябры.

Файлы из `steps` собираются так же:

```bash
g++ -std=c++17 steps/step1_birth.cpp -o step1
```
