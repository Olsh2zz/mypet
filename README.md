# Цифровой питомец

Консольная игра на C++. Практическая работа №1 по алгоритмизации и программированию.

Нужно вырастить щенка: 30 дней следить за голодом, настроением, энергией, здоровьем и чистотой.

## Сборка и запуск

Нужны `git` и `g++` (на macOS: `xcode-select --install`).

```bash
git clone https://github.com/olsh2zz/mypet.git
```

```bash
cd mypet
```

```bash
g++ -std=c++17 src/main.cpp -o pet
```

```bash
./pet
```

### Visual Studio

1. Создать проект «Консольное приложение» (C++).
2. Удалить созданный `.cpp` и добавить `src/main.cpp`: Проект → Добавить существующий элемент.
3. Свойства проекта → C/C++ → Командная строка → в «Дополнительные параметры» дописать `/utf-8`.
4. Запустить: Ctrl + F5.

## Задания

| Задание | Где |
|---|---|
| 1. Рождение питомца | `steps/step1_birth.cpp` |
| 2. Показатели | `steps/step2_stats.cpp` |
| 3. Диалог с пользователем | `steps/step3_dialog.cpp` |
| Границы 0–100 | `limit()` в `src/main.cpp` |
| Третье действие «Уложить спать» | `src/main.cpp` |
| Ввод имени | `src/main.cpp` |
| Цикл `while`, пока питомец жив | `src/main.cpp` |

Дополнительно: энергия, здоровье, чистота, возраст, пауза с сохранением в файл, две концовки.

## Правила

| Действие | Эффект |
|---|---|
| 1. Покормить | голод −30, настроение +5 |
| 2. Поиграть | настроение +30, голод +15, энергия −20, чистота −10; нужно ≥ 20 энергии |
| 3. Уложить спать | энергия +40, голод +10 |
| 4. Искупать | чистота +40, настроение −5 |
| 5. Полечить | здоровье +30, настроение −10 |
| 6. Посидеть рядом | без изменений |
| 0. Пауза | сохранить в `pet_save.txt` и выйти |

Каждый день: голод +5, настроение −5, энергия −5, чистота −5.
Здоровье падает при голоде > 80 (−10), чистоте < 20 (−10), энергии < 10 (−5).

Победа: питомец прожил 30 дней. Поражение: голод 100, настроение 0 или здоровье 0.
