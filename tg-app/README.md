# Цифровой питомец в Telegram

Та же игра, что в консоли, только мини-приложением в Telegram. Щенок анимированный, вместо меню кнопки, а игра сохраняется в облако Telegram.

Открыть в браузере: https://olsh2zz.github.io/mypet/

## Как устроено

Правила игры написаны на C++ в файле `game.cpp`, они такие же, как в `src/main.cpp`. Emscripten компилирует этот файл в WebAssembly, чтобы C++ работал в браузере. Получается файл `web/pet.js`.

Страница лежит в папке `web`. Там `index.html` с разметкой, `style.css` с оформлением и анимациями и `app.js`, который обрабатывает кнопки. Сам `app.js` ничего не считает: он вызывает функции из C++, например `doAction(1)` (покормить) или `getHunger()` (узнать голод), и рисует то, что они вернули.

Сервер не нужен, всё работает на телефоне.

```
tg-app/
├── game.cpp        правила игры
├── build.sh        сборка в WebAssembly
└── web/
    ├── index.html
    ├── style.css
    ├── app.js
    ├── img/        анимации щенка
    └── pet.js      появляется после сборки
```

## Что умеет

Сначала вводишь имя, потом ухаживаешь за щенком теми же шестью действиями, что и в консоли. Миска, мячик, шприц, ванна и лежанка выезжают справа. В ванне щенок сидит в пене, перед сном ложится на лежанку.

Показатели видны полосками: зелёная, если всё хорошо, жёлтая, если пора что-то делать, и красная, если совсем плохо. Сверху счётчик дней.

Игра сохраняется после каждого хода, так что можно закрыть приложение и вернуться потом. Победа заканчивается экраном «ГАВ-ГАВ!» с косточкой, поражение экраном с причиной.

Цвета берутся из темы Telegram, при нажатии телефон слегка вибрирует.

## Публикация

Это нужно сделать один раз:

1. Сделать репозиторий публичным. Бесплатный GitHub Pages работает только с публичными.
2. В настройках репозитория открыть Settings, Pages и в Source выбрать GitHub Actions.

После этого каждый push в `main`, который меняет `tg-app`, запускает сборку. GitHub Actions компилирует C++ и выкладывает страницу на `https://olsh2zz.github.io/mypet/`. Как идёт сборка, видно во вкладке Actions.

## Как подключить к боту

1. Написать [@BotFather](https://t.me/BotFather) команду `/newbot`.
2. Придумать боту название и имя. Имя должно кончаться на `bot`.
3. Отправить `/mybots`, выбрать бота, дальше Bot Settings, Menu Button, Configure menu button.
4. Вставить адрес `https://olsh2zz.github.io/mypet/` и назвать кнопку, например «Питомец».

Теперь у бота внизу есть кнопка, которая открывает игру.

## Собрать у себя

Это не обязательно, GitHub собирает сам. Если хочется проверить локально, нужен [Emscripten](https://emscripten.org/docs/getting_started/downloads.html). Из папки `tg-app`:

```bash
sh build.sh
```

```bash
python3 -m http.server 8000 --directory web
```

Потом открыть `http://localhost:8000`. Вне Telegram игра тоже работает, только сохраняется в браузер.

Анимации щенка взяты с [Icons8](https://icons8.com), стиль Sammy.
