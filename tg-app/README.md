# 📱 Цифровой питомец — Telegram Mini App

Та же игра, что в консоли, только внутри Telegram: с анимированной собачкой, кнопками и сохранением в облаке Telegram.

## Как это устроено

```
tg-app/
├── game.cpp      — логика игры на C++ (те же правила, что в src/main.cpp)
├── build.sh      — сборка C++ в WebAssembly (Emscripten)
└── web/          — то, что открывает Telegram
    ├── index.html — разметка: старт, игра, концовка
    ├── style.css  — оформление и CSS-анимации
    ├── app.js     — кнопки и анимации, вызывает функции C++
    ├── img/       — анимации собачки (Icons8)
    └── pet.js     — собранный C++ (появляется после сборки)
```

1. `game.cpp` компилируется в WebAssembly — это C++, который умеет работать в браузере.
2. `app.js` вызывает функции C++: `doAction(1)` — покормить, `getHunger()` — узнать голод и т. д.
3. Все показатели, правила и концовки считает C++, JavaScript только рисует.

Сервер не нужен: всё работает прямо в Telegram.

## Что есть в приложении

- ввод имени питомца;
- анимированная собачка: виляет хвостом, спит, прыгает, трясётся после купания, грустит и болеет;
- 5 полосок показателей (зелёная → жёлтая → красная), счётчик дней «День N/30»;
- 6 действий, как в консольной версии;
- две концовки: **«ГАВ-ГАВ!»** с косточкой 🦴 и **«ПОРАЖЕНИЕ...»** с причиной;
- автосохранение после каждого хода (в облаке Telegram), можно закрыть и продолжить потом;
- цвета подстраиваются под тему Telegram, кнопки отзываются вибрацией.

## Публикация (один раз)

1. Репозиторий должен быть **публичным** (бесплатный GitHub Pages работает только с ними).
2. На GitHub: **Settings → Pages → Source: GitHub Actions**.
3. После каждого изменения в `main` GitHub Actions сам соберёт C++ и выложит игру на
   `https://<логин>.github.io/<репозиторий>/` (для этого репозитория — `https://olsh2zz.github.io/mypet/`).
   Ход сборки видно во вкладке **Actions**.

## Подключение к боту

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте название и имя бота (имя должно заканчиваться на `bot`).
3. Отправьте `/mybots` → выберите бота → **Bot Settings → Menu Button → Configure menu button**.
4. Вставьте адрес игры `https://olsh2zz.github.io/mypet/` и название кнопки, например `Питомец`.
5. Откройте своего бота — внизу появится кнопка **Питомец**, она запускает игру.

## Сборка на своём компьютере (по желанию)

Нужен [Emscripten](https://emscripten.org/docs/getting_started/downloads.html). В папке `tg-app`:

```bash
sh build.sh
```

Потом запустите любой простой веб-сервер в папке `web`, например:

```bash
python3 -m http.server 8000 --directory web
```

и откройте `http://localhost:8000` в браузере. Без Telegram игра тоже работает, сохранение тогда хранится в браузере.
